# NovelDex source for NoveLA

مصدر Lua لموقع [NovelDex](https://noveldex.io) متوافق مع تطبيق [NoveLA](https://github.com/HnDK0/NoveLA).

## التثبيت

من داخل NoveLA:

1. افتح **Finder → Extensions → Settings**.
2. أضف رابط هذا المستودع.
3. اختر اللغة الإنجليزية ثم ثبّت **NovelDex**.

رابط الفهرس المباشر:

```text
https://raw.githubusercontent.com/omar1654747-svg/novela-noveldex-source/main/index.yaml
```

## الوظائف المدعومة

- أحدث الروايات والبحث.
- بيانات الرواية: العنوان، الغلاف، الوصف، التصنيف، الحالة والتقييم.
- قائمة الفصول.
- قراءة نص الفصل عبر endpoint JSON العام في NovelDex.

> يعتمد المصدر على البنية العامة الحالية للموقع. قد يحتاج إلى تحديث إذا غيّر NovelDex مساراته أو واجهة API.
